How it works

Create Box adds a shape layer behind the selected layers, sized to fit with padding and rounded corners. The layers are parented to it, so moving, scaling or rotating the box moves the group.

Free keeps layers where they are and wraps the box around them. Vertical and Horizontal stack them in timeline order with the gap between. Reorder layers in the timeline to reorder the stack.

Everything updates live as text changes, layers scale or animate. Every setting is on the box layer's Effect Controls, where it can be keyframed. These panel values are the defaults for new boxes; Apply to Box pushes them to selected boxes.

Release bakes the current layout into plain values and keyframes and removes the rig. Boxes can be nested by putting one box inside another.
