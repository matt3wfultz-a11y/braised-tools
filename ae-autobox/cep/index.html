How it works

Create Box adds a shape layer behind the selected layers and parents them to it. Moving, scaling or rotating the box moves the group. Any layer parented to a box is in that box, so editing text, renaming or reordering layers is safe. Use Add to Box and Remove to change what's in a box.

Free keeps layers where they are and wraps the box around them. Vertical and Horizontal stack them in timeline order with the gap between. Reorder layers in the timeline to reorder the stack.

Drag a blue value left or right to change it (Shift for bigger steps, Ctrl/Cmd for finer ones), or click it to type. Everything also lives on the box layer's Effect Controls, where it can be keyframed. These panel values are the defaults for new boxes; Apply to Box pushes them onto selected boxes (keyframed controls are left alone).

Release bakes the current layout into plain values and keyframes and removes the rig.
