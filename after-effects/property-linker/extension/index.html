Mode

    How it works
    1. Select the layers you want to control.
    2. Pick a property and a mode.
    3. Click Link.

    A null such as Opacity Control is added above the layers. It only holds the control (Slider, Angle, Point or Color Control); nothing is parented to it. Each layer gets an expression that reads the control.

    Absolute: every layer takes the control's value. The control starts at the top layer's current value. Keyframes on the layers are overridden.

    Relative: each layer keeps its own value and keyframes. The control multiplies percentages (Opacity, Scale: 100 = unchanged) and adds to everything else (Rotation, Position: 0 = unchanged).

    Selected Properties: twirl open your layers and select the exact properties (effect values, shape fills, text animators…), Ctrl/Cmd-clicking to pick several. Each kind of property gets its own control on one null.

    Add to the selected control null: select an existing control null along with more layers to hook them up to its control.

    Renaming the null or its controls later is safe; After Effects updates the expressions. Each Link is one undo step.
